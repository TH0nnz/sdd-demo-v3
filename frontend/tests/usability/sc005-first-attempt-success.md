# SC-005 Usability Validation

Objective: 95% users succeed on first attempt for primary daily action.

## Population and Sample

- Required N >= 20
- Include all 5 roles: ADMIN, PM, DEPT_MANAGER, EXECUTOR, HR

## Measurement

- Primary actions:
  - EXECUTOR: submit one work entry
  - PM: create/update one task
  - ADMIN: review one hours request
  - HR: create one user
  - DEPT_MANAGER: view member summary and expand task detail
- First-attempt success = task completed without assistance or retry.

## Acceptance

- PASS if first-attempt success rate >= 95% across total sample.
- Record evidence: timestamped observation sheet + event logs.
